# E-commerce Sales & Customer Analysis

A portfolio-ready exploratory data analysis project using the UCI Online Retail dataset.

## Objective
Understand revenue trends, product and country performance, and customer value using Python.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.

## Dataset
UCI Machine Learning Repository — Online Retail (541,909 records).
https://archive.ics.uci.edu/dataset/352/online-retail

Citation: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C5BW33. CC BY 4.0.

## How to run
1. Install Python and Jupyter.
2. Install dependencies: `pip install pandas numpy matplotlib seaborn openpyxl ucimlrepo`
3. Open `ecommerce_sales_customer_analysis.ipynb`.
4. Run all cells. The notebook uses a local `data/Online Retail.xlsx` file if present; otherwise it attempts to fetch the dataset through `ucimlrepo`.

## Analysis
- Data quality checks and cleaning
- Completed-sales revenue calculation
- Monthly revenue trends
- Product and country performance
- Customer RFM segmentation
- Business KPIs and recommendations

## Important
The notebook has been prepared but not executed against the full source dataset in this environment. No numerical findings are claimed until the notebook is run.
